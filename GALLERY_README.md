# 🎨 NPAI Интерактивная галерея

## Описание

Улучшенная визуализационная галерея NPAI с полной документацией из оригинального проектного описания. Галерея содержит все 10 модулей платформы с детальными описаниями, технологиями и ценностью для бизнеса.

## ✨ Основные возможности

### 🎯 Три вкладки

1. **Обзор** - Hero-секция, диаграмма экосистемы, статистика преимуществ
2. **Модули** - Все 10 модулей NPAI с интерактивными карточками
3. **Документация** - Полная документация проекта из NPAI_Project_Description.md

### 🎨 Улучшенные анимации

- **Плавные переходы**: Все элементы анимируются с cubic-bezier для естественного движения
- **Hover-эффекты**: Карточки модулей реагируют на наведение с масштабированием и свечением
- **Пульсирующие точки**: Анимированные data points на hero-секции
- **Градиентное свечение**: Логотип NPAI с эффектом glow
- **Modal анимации**: Модальные окна появляются с эффектом slide-up
- **Плавающие узлы**: Элементы диаграммы экосистемы мягко парят

### 📚 Полная документация модулей

Каждый модуль содержит:
- **Описание** - Что делает модуль
- **Основные функции** - Детальные возможности
- **Технологии** - Используемый стек технологий
- **Ценность** - Конкретные преимущества для бизнеса

## 🚀 Как запустить

### Вариант 1: С главного сайта

1. Откройте http://localhost:8000/
2. Нажмите кнопку **"Интерактивная галерея"** в hero-секции
3. Или кликните на **"Галерея"** в навигационном меню

### Вариант 2: Прямой доступ

Откройте напрямую: http://localhost:8000/gallery.html

## 🎨 Модули платформы

1. **Экологический мониторинг (NPAI Eco)** - Мониторинг выбросов в реальном времени
2. **Видеоаналитика (NPAI Vision)** - Computer Vision для контроля качества
3. **Акустическая диагностика (NPAI Acoustic)** - Предиктивное обслуживание по звуку
4. **Безопасность (NPAI Safety)** - Контроль техники безопасности с AI
5. **Энергоменеджмент (NPAI Smart Grid)** - Оптимизация энергопотребления
6. **Цифровой технолог (NPAI Knowledge)** - LLM-ассистент для инженеров
7. **Тепловизор (NPAI Thermal)** - Тепловизионный контроль оборудования
8. **Аналитика (NPAI Analytics)** - Business Intelligence и дашборды
9. **Marketplace (NPAI Marketplace)** - Платформа для разработчиков
10. **Офлайн-режим (NPAI Offline)** - Автономная работа без интернета

## 🎯 Интерактивные элементы

- **Переключение вкладок** - Обзор / Модули / Документация
- **Модальные окна** - Клик на карточку модуля открывает детальное описание
- **Hover-эффекты** - Все интерактивные элементы реагируют на наведение
- **Анимированная диаграмма** - Экосистема платформы с плавающими узлами
- **Закрытие модалов** - Клик на затемненную область или кнопку ×, или клавиша ESC

## ⚡ Производительность

- **Чистый CSS** - Все анимации на CSS без JavaScript библиотек
- **Легковесная структура** - Один HTML файл (~100KB)
- **Оптимизированные SVG** - Встроенные иконки модулей
- **Lazy animations** - Анимации срабатывают только при видимости

## 🔧 Технологии

- **HTML5** - Семантическая разметка
- **CSS3** - Современные свойства (Grid, Flexbox, Backdrop-filter)
- **Vanilla JavaScript** - Без зависимостей от фреймворков
- **Responsive Design** - Mobile-first подход
